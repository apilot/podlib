## [0.1.0] — не выпущено

Первый публичный выпуск: библиотека-ядро, CLI и GUI для управления
музыкальными библиотеками iPod по USB; проверено end-to-end на iPod Nano 7G.

### Библиотека (`crates/podlib`)

- Доменная модель (треки, плейлисты) за трейтом `LibraryBackend`; адаптер
  libopod — единственный компонент, знающий формат БД устройства
- Запись, безопасная для прошивки: правки собираются в edit-session и
  устанавливаются атомарно; контрольные файлы Nano 7G (HASHAB/CBK)
  переподписываются автоматически
- Поддержка классических iPod (фаза 2): raw-разбор и сериализация iTunesDB,
  re-tiling, подпись HASH58

### CLI (`crates/podlib-cli`)

- Просмотр треков и плейлистов, добавление/удаление/редактирование треков,
  создание/удаление плейлистов, управление составом плейлистов
- Автоопределение точки монтирования iPod

### GUI (`crates/podlib-gui`)

- Подключение в один клик (sudo-mount-флоу) и безопасное извлечение
  (sync → дрейн unmount → power-off, один ввод пароля sudo)
- Drag & drop импорт с transcode через ffmpeg (FLAC/OGG/WAV → AAC) и модалка
  сверки тегов для безтеговых файлов
- Таблицы треков с чекбокс-мультивыбором и «выбрать все»; пакетные действия
  «добавить в плейлист» / «удалить»
- Виды музыки по альбомам и исполнителям, единообразные с видом аудиокниг;
  группы глав m4b с пробой длительности через ffprobe

### Пакетирование

- Release-workflow: тег `v*` собирает tarball'ы Linux x86_64 (gnu) и
  aarch64 (musl) с checksum'ами sha256; `cargo binstall`-метаданные у обоих
  бинарников

### Вклад в upstream

- NULL-safe rank-запросы (в живых firmware-БД встречаются artist-строки с
  NULL-именами), защита от orphan-артистов при удалении и reindex пустых
  ключей приняты upstream и смержены в
  [koriwi/libopod#1](https://github.com/koriwi/libopod/pull/1)
